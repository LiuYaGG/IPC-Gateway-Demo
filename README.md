# IPC Gateway 演示系统

访问地址 https://liuyagg.github.io/IPC-Gateway-Demo/

更新日期 2026 年 11 月 25 日。界面同步正式网关提交 `181d0b4c`。

- 通道聚合拓扑，同时展示南向设备和 MQTT、OPC UA、Web API 北向服务，支持缩放与拖动。
- 历史库配置、点位历史、报警记录采用页签，支持级联筛选、分页和当页 Excel 导出。
- 标签基本配置和数据清洗采用页签，支持标签、分组、设备采集周期的配置展示。
- 新增高可用集群总览、组网配置、主备切换与切换记录模拟。
- 更新 OPC UA 统一公布端点，增加协议诊断、采集诊断和历史点位曲线演示。
- 同步规则编辑、中英文显示、网站图标及页面状态保留。
- 预置 3 个通道、6 台设备、18 个分组和 1500 个混合类型点位，每秒模拟刷新。

此仓库用于 GitHub Pages 静态托管，保存构建产物。数据和操作在浏览器内模拟，刷新页面后恢复。历史查询最多生成 3600 条示例数据。模拟升级、脚本和模型用于界面展示。

高可用地址使用保留测试地址，不连接真实仲裁成员、不生成证书；所有模拟操作不授予真实 PLC 写权限。版本构建、89 次模拟 API 检查和本机浏览器界面检查通过。

正式开源项目 https://github.com/LiuYaGG/IPC.Gateway
